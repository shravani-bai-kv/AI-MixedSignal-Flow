# Reference Repository Study

## Objective

To understand the complete mixed-signal RTL-to-GDS implementation demonstrated in the reference repository.

---

## Repository Goal

The repository demonstrates the integration of an existing analog AMUX macro with digital RTL using OpenLane and the SKY130 Process Design Kit.

---

## Flow Studied

RTL

↓

Synthesis

↓

Floorplanning

↓

Analog Macro Integration

↓

Placement

↓

Clock Tree Synthesis

↓

Routing

↓

DRC

↓

LVS

↓

Final GDSII

---

## Key Learning

- OpenLane automates the digital implementation flow.
- The analog macro is pre-designed and integrated using LEF, LIB and GDS files.
- The final layout is generated by combining the digital implementation with the analog macro.

---

## Conclusion

The repository demonstrates a practical mixed-signal implementation flow using open-source EDA tools. Understanding the purpose of each file and stage is essential before attempting to execute the complete flow.

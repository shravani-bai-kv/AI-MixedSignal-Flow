# AI-Assisted Mixed Signal RTL-to-GDS Flow

## Overview

This repository documents my AI-assisted learning journey in understanding an end-to-end Mixed Signal RTL-to-GDSII Physical Design Flow using the open-source SKY130 PDK and OpenLane.

The work is based on studying and reproducing concepts from the reference repository while documenting every practical experiment, configuration file, debugging step, and observation in my own words.

---

## Objectives

- Learn the complete RTL-to-GDSII physical design flow
- Understand Mixed Signal ASIC design methodology
- Study OpenLane and OpenROAD flow
- Explore SKY130 Open Source PDK
- Learn Analog Macro Integration
- Understand LEF, DEF, LIB and GDSII files
- Practice Linux, Docker and Git for VLSI development
- Document AI-assisted learning and debugging

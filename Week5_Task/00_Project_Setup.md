# Week 5 Project Setup

## Objective

Prepare the project directory structure required for developing, verifying, and integrating a new double-height 2:1 Analog Multiplexer (MUX) in the SKY130 mixed-signal flow.

---

## Folder Structure

The following directories were created to organize the design files, simulation results, layout files, logs, and documentation generated during Week 5.

```text
Week5_Task/
├── 00_Project_Setup.md
├── 01_Existing_MUX_Analysis.md
├── 02_Transistor_Level_Design.md
├── screenshots/
├── netlists/
├── layouts/
├── spice/
├── waveforms/
└── logs/
```


---

## Directory Description

| Directory | Purpose |
|-----------|---------|
| `screenshots/` | Stores screenshots captured during design, simulation, layout, DRC, LVS, and OpenLane execution. |
| `netlists/` | Contains the transistor-level SPICE netlists of the newly designed analog MUX. |
| `layouts/` | Stores Magic layout files (`.mag`), extracted layouts, and related physical design files. |
| `spice/` | Contains ngspice testbenches and simulation input files. |
| `waveforms/` | Stores pre-layout and post-layout simulation waveforms. |
| `logs/` | Contains execution logs generated by ngspice, Magic, Netgen, and OpenLane. |

---

## Commands Used

```bash
mkdir -p Week5_Task

cd Week5_Task

mkdir -p screenshots netlists layouts spice waveforms logs
```
